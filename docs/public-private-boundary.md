# Public Distribution Boundary

This repository is a generalized public distribution of architectural patterns developed and exercised in a private local-first agent-control laboratory.

The public code preserves the control-plane mechanisms that matter: typed intake, provider seam, scope control, independent verification, evidence, gates, deterministic policy, durable state, retry rules, lifecycle ownership, and bounded supervision.

Examples and supervision channels in this repository are synthetic. Operational data, real decision records, real runtime databases, logs, evidence artifacts, credentials, endpoints, and private automation are intentionally excluded.

The public repository is intended to have independent Git history rather than expose the history of the private laboratory.
